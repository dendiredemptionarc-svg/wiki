# GBOYSPECIAL.COM COMMUNITY DIRECTORY

### "CREDIT WHERE CREDIT'S DUE"

Welcome to the community wallet directory. This list is here so that **Neuko Ai** community members can easily find each other in order to send credits as a gift or reward for actions within the ecosystem.

Those actions could come in any form: awesome videos, banger threads, cool content, or even simple kindness, helpfulness, and onboarding gestures. If you see it as worthy of a few credits, you'll find them here.

::: info HOW TO USE

1. **Search:** Use the search bar in the terminal below to find a community member.
2. **Copy:** Click to copy their Solana wallet address.
3. **Transfer:** Head to your [gboyspecial profile](https://gboyspecial.com) credits page.
4. **Send:** Paste the address into the **'Receiver Solana Address'** bar, enter the amount, and hit send.
   :::

::: warning PLEASE NOTE

- **Handles:** The list is sorted by **X Handles**. If a member uses a different nickname, it is included in brackets and is searchable.
- **Safety:** Only use these wallets to send `gboyspecial` credits. We recommend not interacting with unfamiliar wallets away from the official site.
- **Security:** Please take the same care with wallet security and safety as you would anywhere else in Web3.
- **No Obligation:** There is **no obligation** to send credits. This is a community tool; it is entirely up to the individual.
  :::
